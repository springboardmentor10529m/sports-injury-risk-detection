# MotionGuard AI Frontend

This folder contains the recovered frontend source, compiled assets, and standalone Vite configuration for the Sports Injury AI application.

## Start

```powershell
npm install
npm run dev
```

Open http://127.0.0.1:5175.

The frontend expects the FastAPI backend at `http://127.0.0.1:8000`.

## Structure

- `src/` — recovered React pages, routes, services, context, and UI components
- `dist/` — preserved compiled MotionGuard build and static assets
- `index.html` — Vite entry point
- `vite.config.js` — local development and preview configuration
