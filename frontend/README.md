# SafeMove — Frontend Application

Next.js (App Router), React, and Tailwind CSS web application for the SafeMove platform.

## Features
- **Role-Based Dashboards**: Tailored views for Athletes, Coaches, Physiotherapists, Sports Scientists, and Admins.
- **Biomechanical Video Player & Pose Overlay**: Interactive canvas rendering 15 anatomical keypoints overlaid directly on video.
- **Kinematics Charts & Anomaly Visualizer**: Real-time joint angle trajectories, velocities, asymmetries, and deviation severity alerts.
- **Athlete Management & Uploads**: Secure video upload with instant pipeline analysis tracking.

## Setup & Running

```bash
# 1. Install dependencies
npm install

# 2. Run Next.js development server
npm run dev
```
