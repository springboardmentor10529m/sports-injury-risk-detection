# SportShield Frontend Application

The active React 18 + Vite frontend application for SportShield is located in the [`backend/frontend`](../backend/frontend/) directory.

---

## 🛠️ Tech Stack
- **React 18**: Component-driven user interface
- **Vite**: Ultra-fast frontend build tool & development server
- **HTML5 Canvas**: Frame-by-frame 33-point skeletal landmark visualization
- **Vanilla CSS**: Clean, responsive styling with dark-mode aesthetic
- **Fetch API**: REST communication with FastAPI backend

---

## 🚀 Running the Frontend

```bash
# Navigate to active frontend workspace
cd ../backend/frontend

# Install dependencies
npm install

# Start Vite dev server
npm run dev
```

The web application will open at `http://localhost:5173`.
